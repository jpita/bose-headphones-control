Raw BMAP console

Packet format is <fblock> <func> <op> <len> <payload>. Operators: 01 GET, 02 SETGET, 05 START. 00 is SET, which the firmware refuses with error 5 on most blocks. Read all mode configs: 1f 01 05 00. Read the battery: 02 02 01 00.
